# Сайт-резюме Igor Mavl

Одностраничное резюме на четырёх языках: русский, украинский, английский и иврит (справа налево). Разделы: проекты со скриншотами, опыт, навыки, «Что меня вдохновляет», блог и контакты.

Две версии сайта:

- `index.html` — спокойная версия в виде резюме.
- `portfolio.html` — версия-портфолио Gori4ka: крупные карточки работ, превью сайтов за курсором, блок YouTube, интерактивный первый экран. Чтобы сделать её главной, переименуйте в `index.html` (а старую — во что-то другое).

В `portfolio.html` в начале скрипта есть настройки:

- `GA_ID` — ID Google Analytics 4 (`G-XXXXXXXXXX`). Пусто = аналитика выключена. Сайт отправляет события кликов по email, Telegram, телефону, проектам, PDF и смене языка.
- `SHOW_PDF` — показывать кнопку «Резюме (PDF)»; файлы `Igor-Mavl-CV-UA.pdf` и `Igor-Mavl-CV-EN.pdf` должны лежать рядом.

Остальные файлы:
- `photo.jpg` — фото.
- `img/` — скриншоты проектов (haregulator, redback, DevBox, игра).

## Как редактировать

Откройте `index.html` в любом редакторе и найдите блок `КОНТЕНТ` в начале `<script>`:

| Что | Где |
| --- | --- |
| Имя, фото, подпись | `PROFILE` |
| Email, телефон, Telegram, YouTube, GitHub, LinkedIn, DOU, Work.ua | `CONTACTS` (пустая строка = не показывается) |
| Проекты со скриншотами | `WORKS` (`group: "client"` — по работе, `"own"` — свои) |
| Сетка «Другие сайты на WordPress» | `MORE_SITES` (миниатюры 800×450 в `img/`) |
| Ultimate Member и старые сайты | `ALSO` |
| Места работы | `EXPERIENCE` |
| Навыки | `SKILLS` |
| Посты блога | `POSTS` |
| Все остальные тексты (вступление, «Что вдохновляет», подписи) | `I18N` |

Тексты пишутся сразу на четырёх языках: `{ ru: "...", uk: "...", en: "...", he: "..." }`.

В текстах из `I18N` можно ставить ссылки так: `[[devbox|DevBox]]`. Адреса для них лежат в `LINKS`.

## Как добавить пост в блог

Скопируйте любой объект в `POSTS` и поменяйте:

- `slug` — латиницей, без пробелов (станет ссылкой `#post-slug`);
- `date` — `"ГГГГ-ММ-ДД"`;
- `title` и `body` на четырёх языках.

Формат текста: пустая строка — новый абзац, `## ` — подзаголовок, `- ` — пункт списка, `` `код` ``, `**жирный**`, `[ссылка](https://...)`.

## Как добавить проект

Положите скриншот 1200×675 в `img/` и добавьте объект в `WORKS` по образцу соседних.

## Фон

Два мягких цветных пятна в `<div id="bg">`: синее плавно идёт за курсором, бирюзовое тянется следом. Без мыши (на телефоне или когда курсор стоит дольше 4 секунд) они медленно дрейфуют сами. Текст остаётся контрастным: фон под ним только слегка тонируется.

- Цвет и яркость — токены `--glow-a` и `--glow-b` в начале `<style>` (отдельно для светлой и тёмной темы).
- Размер — `.glow.a` и `.glow.b` в CSS.
- Скорость — функция `glowField` в скрипте: `k` (как быстро догоняет курсор) и `0.025` (запаздывание второго пятна).

Если в системе включено «уменьшение движения», пятна стоят на месте.

## Ссылки на нужный язык

Добавьте к адресу `#ru`, `#uk`, `#en` или `#he`, например `.../index.html#en` для англоязычного рекрутера. Без метки язык берётся из браузера посетителя.

## Как выложить бесплатно

Загрузите всю папку (`index.html`, `photo.jpg`, `img/`) на любой статический хостинг:

- **Netlify Drop**: перетащите папку `resume-site` на https://app.netlify.com/drop (вы уже пользуетесь Netlify для DevBox и игры).
- **GitHub Pages**: репозиторий `gori4ka-dev.github.io`, загрузите файлы, сайт будет по адресу `https://gori4ka-dev.github.io`.

## Анимации при прокрутке (версия 2)

Обе страницы подключают общие файлы `motion.css` и `motion.js`. Страница помечается атрибутом на `<body>`: `data-motion="cv"` для резюме и `data-motion="portfolio"` для портфолио.

- **Анимации проигрываются каждый раз.** Блок, ушедший с экрана, снова прячется. При прокрутке вниз блоки приходят снизу, при прокрутке вверх — сверху, а цифры считаются заново. Чтобы анимации шли только один раз, поставьте в начале `motion.js` `const REPLAY = false;`.
- **Что анимируется** задаёт список `RULES` в начале `motion.js`. Каждая строка — это CSS-селектор и вариант появления: `up`, `side`, `scale`, `pop`, `blur`, `fade`, `wipe`. Чтобы блок перестал анимироваться, удалите его строку.
- **Цифры, которые считаются от нуля**, задаёт `COUNTERS`. **Карточки с подсветкой за курсором** задаёт `SPOTS`.
- **Бегущая строка технологий** есть только на портфолио: список `TECH` в `motion.js`, стиль в блоке `.m-marquee` в `motion.css`.
- **Если у посетителя включено «уменьшить движение»**, анимации отключаются. Остаются только полоска прогресса, кнопка «наверх» и подсветка раздела в меню.
- **Без JavaScript** весь контент виден сразу: блоки скрывает сам скрипт, перед тем как анимировать.

## Дуб на фоне (версия 3)

За контентом растёт дуб, и его рост привязан к прокрутке всей страницы. Вверху виден пень на корнях. В середине поднимаются массивный ствол и кривые ветви. Ближе к концу вместо листьев появляются цветные логотипы технологий, а в самом низу они опадают. При прокрутке вверх дуб «сворачивается» обратно. Логотипов 74: PHP, JavaScript, Java, C#, C++, Vue, Python, Go, Docker и другие.

- **`tree.js`** рисует дуб на двух неподвижных холстах под контентом (`z-index: -1`):
  - **Древесина** перерисовывается только пока дуб растёт или сворачивается, сам он не качается.
  - **Логотипы** заранее рисуются по одному в маленькие картинки (спрайты) для текущей темы. Каждый кадр их только расставляет, поэтому покачивание почти ничего не стоит: около 1–2 мс на кадр.
- **Где стоит дуб.**
  - На широком экране ствол стоит в поле справа от текста, а крона тянется над страницей.
  - На иврите всё зеркально: ствол слева.
  - На телефоне дуб стоит по центру.
  - Форма задаётся в начале `tree.js`: `LIMBS` — главные ветви (угол, длина, толщина), `MAX` — сколько раз ветви делятся. Дерево строится из постоянного зерна `rng(20261110)`, поэтому у всех посетителей оно одинаковое. Другое число даст другой дуб.
- **Над колонкой текста** дуб затушёван примерно до 22%, чтобы текст оставался читаемым. Сила затушёвки — `0.78` в `fadeAt` и в градиенте в конце `drawWood`, ширина перехода — `FEATHER`.
- **Цвета.**
  - Кора и мелкие ветки — `theme()`, отдельно для светлой и тёмной темы.
  - Лёгкая «листва» вокруг логотипов — цвет `canopy`.
  - Логотипы берутся в фирменных цветах. Слишком тёмные на тёмной теме и слишком светлые на светлой автоматически осветляются или затемняются.
- **Набор логотипов** лежит в `tech-icons.js`. Логотипы взяты из [Simple Icons](https://simpleicons.org) (лицензия CC0) и принадлежат своим владельцам. Поменять набор можно двумя способами:
  - **Руками.** Каждая запись — `{ t: "название", c: "#цвет", p: "SVG-путь в квадрате 24×24", x: "текст поверх (необязательно)" }`. Так сделан C#: в Simple Icons его нет, поэтому это шестиугольник с надписью.
  - **Генератором.** Поправьте список `WANT` в `tools/extract-icons.mjs` (имена как на simpleicons.org) и выполните в папке `tools`: `npm install simple-icons`, затем `node extract-icons.mjs ../tech-icons.js`. Папку `tools` на хостинг выкладывать не обязательно.
- **Без `tech-icons.js`** вместо логотипов будут цветные точки.
- **Если у посетителя включено «уменьшить движение»**, дуб просто показывает состояние для текущего места страницы: без покачивания, без падающих логотипов и без плавного догоняния.
- **Убрать дуб**: удалите две строки `<script src="tech-icons.js">` и `<script src="tree.js">` в `index.html` и `portfolio.html`.
